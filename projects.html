Tic-Tac-Toe Game

A C++ console-based Tic-Tac-Toe game featuring interactive player turns and win validation.

How I built it

  1. Designed a 3x3 grid representation using a 2D array in C++.
  2. Implemented a game loop to alternate turns between player X and player O.
  3. Added input validation to prevent players from overwriting existing moves.
  4. Wrote win-checking algorithms for rows, columns, and diagonals.

Technologies Used

  • C++
  • Console Input/Output
  • Git & GitHub for Version Control

Simple Banking System

A C++ console-based application for managing customer accounts, handling secure deposits and withdrawals, and checking real-time balances.

How I built it

  1. Created structured data types (`struct`) to hold user account information and balances.
  2. Implemented a menu-driven loop using `switch` statements to handle choices for deposits, withdrawals, and balance checks.
  3. Wrote custom functions to validate input and prevent negative deposits or overdraft transactions.
  4. Managed program execution and control flow using procedural logic.
